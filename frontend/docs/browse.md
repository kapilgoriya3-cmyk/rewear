# ReWear — Browse / Explore Page

## Page Purpose

The Browse page is where users discover clothing available for exchange.

It should feel like a clean, premium community wardrobe rather than a traditional shopping store.

---

### Eyebrow

`THE COMMUNITY WARDROBE`

### Heading

`Explore clothing`

### Description

`Find pieces nearby or discover something new to you.`

### Action Button

`＋ List an item`

## 2. Search

`Search dresses, jackets, Zara, size M...`

button.

## 3. Category Filters

- All
- Nearby
- Dresses
- Tops
- Jackets
- Shoes
- Bags
- Like new

## 5. Card Interaction

Each clothing card should be clickable so it can eventually open the Item Details page.

The heart button should allow the user to save/wishlist an item.

Do not implement a backend yet. Frontend interaction/state is enough for now.

---

## 6. Visual Style

Follow the same ReWear visual language as the Home page:

- Warm off-white/cream background
- Dark charcoal text
- Sage green accent
- White cards
- Rounded corners
- Soft shadows
- Clean typography
- High-quality clothing imagery
- Generous spacing
- Premium editorial fashion aesthetic

The Browse page should visually feel like the same website as the Home page.

---

## 7. Desktop Only

For now, build only the desktop version.

Do not implement mobile/tablet responsive behavior yet.

---

## 8. Important

Use the existing:

- Navbar
- React Router
- Assets
- CSS conventions

Do not rebuild the entire application.

Only build the Browse / Explore page.
