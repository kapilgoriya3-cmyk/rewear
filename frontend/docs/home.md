# ReWear — Home Page

## Page Purpose

The Home page is the main landing page of ReWear.

Its purpose is to:
- Explain what ReWear is.
- Encourage users to explore clothing.
- Show the sustainability impact.
- Highlight available clothing.
- Explain how ReWear works.
- Encourage users to participate.

---

## 1. Navigation Bar

The navbar should contain:

### Left
- ReWear logo: `rewear.`

### Center
- Home
- Explore
- How it works
- Community

### Right
- Search icon/button
- Wishlist/Swaps icon
- Log in
- Join ReWear
- Profile avatar

The navbar should remain visually clean and premium.

## 6. How ReWear Works

### Eyebrow

`SIMPLE BY DESIGN`

### Heading

`How ReWear works`

Create three steps.

### 01 — LIST

Heading:

`Give an unworn piece a new chance.`

Explain that users can list clothing they no longer wear.

### 02 — MATCH

Heading:

`Find a fair exchange.`

Explain that ReWear helps users discover suitable pieces and provides estimated swap values.

### 03 — EXCHANGE

Heading:

`Chat, agree and swap.`

Explain that users can communicate, agree on the exchange and complete the swap.

## 7. Visual Style

The Home page should follow the ReWear premium marketplace design.

### Colors

- Background: warm off-white / cream
- Main text: dark charcoal
- Accent: sage green
- Secondary: light sage
- Supporting accent: warm orange
- Cards: white

### Design

- Minimal
- Premium
- Editorial fashion aesthetic
- Sustainability-focused
- Generous whitespace
- Rounded cards
- Soft shadows
- High-quality clothing photography
- Clean typography
